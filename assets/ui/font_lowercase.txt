# SawGod overlay font: lower-case letters a-z as our own 8x8 tiles in the style of the WSC system font (which
# has upper case only). Our art, checked in here; nothing is extracted from a ROM or patch. The shapes follow
# the lower case of a fan-made WSC SaGa font (confirmed the shapes may be used).
# Format: a line with the letter, then 8 rows of 8 cells: X = white stroke, . = empty. The font's black
# shadow (one pixel right of and below each stroke, where there is no stroke) is added by the overlay
# (src/engine/ui_skin.cpp). CMake compiles this file into the game (ui_font_lowercase.inc in the build tree).
