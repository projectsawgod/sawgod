The original 2002 WonderSwan Color *魔界塔士 Sa・Ga* (Makai Toushi SaGa), run from SawGod's static recomp
(partially decompiled for readability) with no changes or QoL features: original Japanese text, menus, sound and
cartridge saves, in a window with gamepad support. This is a one-time release and won't be updated. For the
English translation, Game Boy and Enhanced modes and everything else, get
[SawGod](https://github.com/projectsawgod/sawgod/releases/latest).

**You need your own Japanese WonderSwan Color ROM** (`.wsc`). No ROM or game data is included.
