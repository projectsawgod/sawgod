# SawGod Vanilla input mapping. Edit beside the executable (beside the .app on macOS).
# Defaults below are inactive until you remove their leading #.
# Format: DEVICE WSC_BUTTON CONTROL [DEVICE CONTROL]; # starts a comment.
# Each line replaces that button's keyboard or gamepad bindings (up to two).
# Devices: key (SDL scancode), button (SDL gamepad button or south/east/west/north),
#   axis (SDL gamepad axis with + or -). Use none to clear, e.g. key a none.
# A second pair must use the same input type (keyboard or gamepad).
# Omitted buttons keep defaults. Esc, F11 and Alt+Enter are reserved; deadzone is 40%.
